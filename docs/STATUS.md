# Mathematical scope

Transformatics is Hunter Bown's proposed organizing viewpoint and a collection of
teaching material. It has not established an unforced Navier–Stokes solution.

| Subject | Standing |
| --- | --- |
| Three-dimensional unforced Navier–Stokes regularity (ROOT) | Open |
| The local sufficient estimate E-prime | Open |
| Smoothly forced finite-time breakdown | Imported from OpenAI's construction |
| Local research examples | Finite or conditional results, with their hypotheses and corrections preserved |

The [claim register](../textbook/claims.md) links each statement to its argument,
assumptions, and evidence. The [external result record](../formalization/external_ns/README.md)
and local Lean records specify exactly what those checks cover. Computational
examples and formula tests have their own stated scope.

Read the [source guide](sources.md) before using the research companion notes.
