# Reading the sources

Start with a chapter and follow its links to the argument it uses. The
[claim register](../notes/claims.md) records the scope, dependencies, source
files, and corrections for each selected result. Its JSON version pins source
hashes; the website builder checks those hashes and all local links.

The notes in `references/` include finite constructions, failed routes, and
subsequent corrections. Their dates describe the mathematical sequence. A
historical positive label does not override a later correction or the current
[mathematical scope](STATUS.md).

Exact identities, numerical experiments, written arguments, and Lean checks are
different kinds of evidence. Formal records retain theorem names, source pins,
axioms, and outcomes. Machine-specific execution paths have been omitted.
Hashes quoted in dated review records identify the versions reviewed then,
before the publication cleanup of filenames and links. The claim register and
publication inventory record the current files' hashes.

Classical sources and OpenAI's externally authored results remain credited where
they are used. See the [literature guide](../notes/chapters/references.md) and
[credits](../notes/chapters/credits.md).
